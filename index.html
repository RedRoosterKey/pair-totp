Verify each other with a shared code

Scammers can now use AI to copy someone's voice, or even their face on a video call, from a short recording. Then they call pretending to be a family member, friend or colleague who needs help. When the voice sounds right, you need a simple check that can't be faked.

pair-totp gives the two of you a shared code. Afterwards your authenticator apps show the same 6-digit code, which changes every 30 seconds. On a call, ask the other person to read you their code. If it matches yours, it's really them.

You'll need:

  • Both people, with this screen in front of you
  • An authenticator app on each phone

Get an authenticator app first

We recommend Ente Auth. It's free and open source, and it works offline without an account. Already have an authenticator app? Any app that does 6-digit, 30-second codes will work.

Which do you have? On a computer, scan the code with your phone's camera. On a phone, tap the link.

You're paired

Both apps should now show the same 6-digit code, changing every 30 seconds. Compare them now. If they don't match, delete both entries and start over.

How to verify each other

  1. When the other person calls or messages you and you want to be sure it's really them, ask them to read out the current code from their "Shared Code with…" entry.
  2. Check it against the code in your own app. Don't read yours out first.
  3. If it matches, it's them. If it doesn't, hang up and contact them another way.
  4. For them to verify you too, wait for the next code and swap roles.

If a code is off by one just as it changes, wait for the next one and try again. Keep the entry private. If either phone is lost, delete the entry and run pair-totp again.
